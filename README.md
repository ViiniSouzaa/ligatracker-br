LigaTracker BR é uma plataforma web privada criada para acompanhar um campeonato amador de League of Legends entre amigos. O sistema terá times pré-cadastrados, contendo jogadores titulares e reservas organizados por lane/função (Top, Jungle, Mid, ADC e Support), com foco em análise competitiva e evolução dos participantes ao longo da temporada.

A plataforma utilizará a API da Riot Games para coletar e exibir informações públicas dos jogadores, incluindo:

Elo/ranque atual
Histórico de elos anteriores
Taxa de vitória (winrate)
Campeões mais jogados
Estatísticas de partidas ranqueadas
Histórico de desempenho ao longo do campeonato

O objetivo do projeto é criar uma experiência semelhante a sites de estatísticas competitivas como OP.GG
, porém focada exclusivamente em um campeonato fechado e personalizado entre amigos. Os dados serão utilizados para gerar páginas de times, perfis de jogadores, rankings internos, comparações de desempenho e acompanhamento da evolução dos participantes durante o torneio.

Inicialmente, o sistema será acessado apenas pelos participantes do campeonato e não terá funcionalidades comerciais. Futuramente, novas métricas e análises poderão ser adicionadas conforme o desenvolvimento evoluir.

As APIs planejadas para uso incluem:

Summoner API
League API
Match API
Champion Mastery API

A aplicação será desenvolvida como um site web responsivo com backend próprio para armazenamento e processamento das estatísticas coletadas.
